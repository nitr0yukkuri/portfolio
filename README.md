3D人生ゲーム風ポートフォリオ
概要
これは、Three.jsを使用して作成された、人生ゲーム風のインタラクティブなポートフォリオサイトです。

特徴
3D表現: Three.jsを使用して、ボード、駒、背景などが3Dで表現されています。

インタラクティブな操作: 矢印キーやボタンで駒を動かし、マスや駒をクリックすることで、プロフィールや実績の詳細をサイドパネルに表示できます。

レスポンシブデザイン: スマートフォンでも操作しやすいように、モバイル用の操作ボタンが配置されています。

アニメーション: Tween.jsを使用して、駒の移動やUIの表示に滑らかなアニメーションが実装されています。

使い方
index.html を開くと、スタート画面が表示されます。

「ポートフォリオを見る」ボタンをクリックすると、portfolio.html に遷移し、3Dのポートフォリオが表示されます。

キーボードの ◀ ▶ キー、または画面上のボタンで駒を移動できます。

駒やマスをクリックすると、左側に詳細情報が表示されます。
