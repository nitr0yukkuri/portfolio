# 🎲 3D人生ゲーム風ポートフォリオ

これは **Three.js** を使用して作成された、人生ゲーム風のインタラクティブなポートフォリオサイトです。

---

## 📝 概要
3Dボード上で駒を動かしながら、プロフィールや実績を直感的に確認できるポートフォリオです。  
マスや駒をクリックするとサイドパネルに詳細が表示され、モバイルでも操作しやすい UI を備えています。

---

## ✨ 特徴
- **3D表現**  
  Three.js を使用し、ボード・駒・背景などを立体的に表現しています。

- **インタラクティブな操作**  
  矢印キーや画面上のボタンで駒を操作できます。  
  マスや駒をクリックすると、サイドパネルに詳細が表示されます。

- **レスポンシブデザイン**  
  スマートフォンでも操作しやすいように、モバイル用のボタンを配置しています。

- **アニメーション**  
  Tween.js により、駒の移動やUIの表示が滑らかにアニメーションします。
