# 🎲 3D Board-Game Portfolio

[日本語](README.md) | [English](README.en.md)

An interactive portfolio website inspired by a life-board game, built with **Three.js**.

---

## 📝 Overview

A portfolio where you move a piece around a 3D board to explore a profile and achievements. Clicking a space or a piece shows details in a side panel, and the UI is designed to be easy to use on mobile as well.

---

## ✨ Features

- **3D presentation**  
  Three.js renders the board, pieces, background, and other elements in 3D.

- **Interactive controls**  
  Move the piece with the arrow keys or on-screen buttons.  
  Click a space or piece to display details in the side panel.

- **Responsive design**  
  Includes mobile controls for easier use on smartphones.

- **Animation**  
  Tween.js smoothly animates piece movement and UI transitions.

---

## 🧩 Tech stack

**Frontend**
